## 4. 必須セクション（骨子）

### 4.1 概要 — 「METAR は平気なのに、最後の 500ft で牙を剥く」

- 前回 [METAR/TAF（2-3-2）](/articles/PPL-2-3-2_MetarTafAndWeatherReports) で「文字から 3D 景色」を読めるようになった。**ばってん、着陸直前だけ別の空が来る** — それがウィンドシアー。
- 道真ペルソナ: 博多弁。**比喩は九州・東北どちらか**（Phase 1 完走記念で東北グルメも可。例: 突然沸騰する鍋の蓋）。

### 4.2 ウィンドシアー — 低高度の「風の断層」

| 概念 | PPL で押さえる要点 | 試験トラップ |
|------|-------------------|--------------|
| **ウィンドシアー** | 短距離・短時間での風向風速の**急変** | 「高度が高いほど常に激しい」と混同させない |
| **マイクロバースト／ダウンバースト** | 強い下降気流＋地面で**放射状に広がる風** | 着陸前の**追い風→向かい風**切り替え |
| **ガストフロント** | 急な風向変化・突風の前線 | METAR の `G`（ガスト）との関係 |

- [PPL-2-2-1](/articles/PPL-2-2-1_WindObservationBasics) の「読んだら真・聞いたら磁」、2-3-2 の **TEMPO/BECMG** と接続。
- **運用**: 管制・ATIS・PWS（簡潔に）— 条文断定なし。

### 4.3 火山灰 — エンジンの「砂嵐」

- 灰の成分（ガラス質粒子）→ **エンジン EGT 上昇・失速・計器障害**（定性）。
- 日本周辺の意識（活火山帯）— 数値・距離は試験レベルの一般論。
- **回避**: SIGMET/通報・視程・引き返し（詳細は 2-3-4 で SIGMET 本格化。ここでは**予告**）。

### 4.4 ☕ 五感比喩（空中待機）

- 例: **青森・いかの塩辛** や **博多のとっぽき** — 「表面は静か、底が急に熱い／塩辛い」＝シアーの罠。
- アフィリエイト枠はプレースホルダ可（Phase 1 同型 `not-prose` div）。

### 4.5 Check Six（3〜4 問）

1. **ウィンドシアーの定義** — 低高度・短時間の風の急変（着陸局面）。
2. **ダウンバースト／マイクロバースト** — 下降気流＋地面散逸、着陸前の追い風罠。
3. **火山灰のエンジン影響** — ガラス質粒子・EGT・推力低下（選択肢の型）。
4. **（任意）METAR と SPECI** — 急変時 SPECI が出たらシアー/CB 疑い（2-3-2 復習）。
