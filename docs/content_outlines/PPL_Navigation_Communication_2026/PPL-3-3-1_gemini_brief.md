## 1. 記事目的

**VFR 運航** と **VMC（有視界気象条件）** を**航法・運航実務の読み方**から整理。管制圏・PCA・進入管制区等の**条文正本は法規 [PPL-5-4-1](../../src/content/lessons/PPL-5-4-1_AirspaceAndFacilitiesOverview.mdx)** — 本記事は**地図・計画・目視航法と空域の関係**に集中。3-1-3 の図上記号と接続。

## 2. 学習目標

- [ ] **VFR** — Visual Flight Rules — と **IFR** の違いを、航法手段（地文 vs 計器）と結びつけて説明できる。
- [ ] **VMC** の代表的要素（視程、雲との距離等 — PPL 試験レベル）を列挙できる（数値は代表値、詳細条文は 5-4-1 へ）。
- [ ] 航空図上の**禁制・制限・危険・管制空域**を読み、ルート計画に反映する**考え方**を述べられる。

## 3. 必須セクション

1. **概要** — 航法の技術が揃った。**「どの空を、どんな天気で、目で飛べるか」** — VFR の枠組み。
2. **VFR vs IFR** — 目視参照の可否、計器航法との関係（3-2-2 復習）。PPL は VFR 中心。
3. **VMC** — 最低視程・雲離隔の代表値（試験用）。METAR との接続（2-3-2 軽く）。**条文は 5-4-1 正本** Callout 必須。
4. **空域の読み方（航法視点）** — 図上の色・境界、進入・管制の**計画への影響**（進入許可・通信 4-x 予告）。詳細分類は 5-4-1 へリンク。
5. **🍜 五感比喩** — 例: 霧の博多湾 — VMC 割れで VFR 不可。
6. **💡 Check Six（3〜4 問）**
   - VFR の定義 — 目視で地表・障害物を参照。
   - VMC 未達時 — VFR 運航不可（一般論）。
   - 禁制空域 vs 制限空域 — 図上の読み（定性）。
   - 法規の正本はどこか — PPL-5-4-1（メタ問題）。
7. **📝 まとめ** — 次回「空間識失調の基礎」（3-3-2）— Phase 1 締め前。
