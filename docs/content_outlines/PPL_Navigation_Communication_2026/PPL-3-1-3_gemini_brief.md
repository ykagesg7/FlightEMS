## 1. 記事目的

**航空図（Aeronautical Chart）** の PPL 向け読み方を整理。**ランベルト正角円錐図法**、**縮尺**、**記号・凡例**を中心に、地文航法・DR 計画（3-1-4, 3-1-5, 3-2-1）の**紙／PDF 地図リテラシー**を確立する。日本の WAC・VFR ターミナル等の名称は例示レベル（版数・細部は AIP Phase 2 予告）。

## 2. 学習目標

- [ ] **正角図法**（特にランベルト）の目的 — 針路・角度を保ちやすい — を説明できる。
- [ ] **縮尺**（1:500,000 等）の読み方と、図上距離から地上距離（NM）への換算の考え方を述べられる。
- [ ] 主要な**記号**（空港、禁制・制限、障害物、通信施設等）を凡例と照合して読める。

## 3. 必須セクション

1. **概要** — 座標（3-1-1）と要素（3-1-2）が揃った。**地図を「飛行計画のキャンバス」として読む**。
2. **投影法** — 地球 → 平面。正角・正積・正射の一言比較。**ランベルト正角円錐**を PPL 主役に。試験トラップ: メルカトルとの混同。
3. **縮尺と距離** — 代表縮尺、図上 cm/mm と NM。エクイディスタント curve は深掘り不要。
4. **記号と凡例** — 色・線種・記号の体系。VFR 最低安全高度等は**図上の存在**を示す（詳細運用は 3-3-1）。
5. **🍜 五感比喩** — 例: 福岡市街地図 vs 九州全图 — 縮尺が変わると見えるものが変わる。
6. **💡 Check Six（3〜4 問）**
   - ランベルト図法の特徴（正角）。
   - 縮尺 1:500,000 の意味。
   - 記号読み（禁制空域・空港等 — 選択肢形式）。
   - 正角図法で針路をそのまま引ける理由（定性）。
7. **📝 まとめ** — 次回「風力三角形と航法計算尺」（3-1-4）予告。
