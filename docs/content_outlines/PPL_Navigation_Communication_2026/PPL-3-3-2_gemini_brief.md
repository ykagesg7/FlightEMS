## 1. 記事目的

**空間識失調（Spatial Disorientation）** の分類と**前庭系錯覚**、**回復手順**を PPL 向けに整理。Subject 3 Phase 1 の**締め** — 航法技術があっても**体が嘘をつく**リスク。Phase 2 の HP 大量設問（低酸素・ADM 等）への入口。CPL 直接対応は薄いが PPL 駆動クラスタが厚い。

## 2. 学習目標

- [ ] **空間識失調** — 実際の姿勢・運動と感覚の不一致 — を定義できる。
- [ ] 代表的 **前庭錯覚**（傾斜錯覚、コリオリ効果、重力錯覚等）を PPL 学科レベルで列挙できる。
- [ ] **回復の基本** — 計器を信じる、外界参照、急な機動を避ける — を述べられる。

## 3. 必須セクション

1. **概要** — 3-3-1 で VFR の枠を学んだ。**IMC や夜、内耳はパイロットを裏切る** — Phase 1 最終テーマ。
2. **空間識失調とは** — 視覚・前庭・体性感覚の不一致。VFR→IMC 移行の危険性。
3. **錯覚の分類** — 前庭系（傾斜、回転、コリオリ）、視覚系（偽地平線等）、組合せ。試験頻出 3〜4 種に絞る。
4. **予防と回復** — **計器飛行**への移行、180° ターンの限界、Trusted instruments。実運航は訓練・IFR 資格の話は扉のみ。
5. **🍜 五感比喩** — 例: 酔い船 — 内耳と目の不一致（博多港のフェリー等）。
6. **💡 Check Six（3〜4 問）**
   - 傾斜錯覚 — 長時間小傾斜後の水平感の狂い。
   - コリオリ効果 — 2 軸回転の組合せ（定性）。
   - 回復の第一選択 — **計器を信頼**。
   - VFR パイロットが IMC に入ったときの典型結果（選択肢 — 統計的危険）。
7. **📝 まとめ** — Subject 3 Phase 1 完走。Phase 2（磁気偏差、GNSS、HP 深化）予告。
