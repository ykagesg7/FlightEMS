## 📚 詳細解説：コックピットタスクの作法と優先順位

下（コックピット内）を見るには、命を守る「作法」と「優先順位」がある。
これを破った瞬間に、お前の居場所は消えて無くなるばい！

### 1. P（Point）：コックピット仕事は「4番目」たい！

教範（Flying Fundamentals 6.2.2）に書かれておる、ウイングマンの優先順位ば見てみんね！

1. **CLEAR!**（衝突回避・クリアリング）
2. **Visual**（リーダーや他機を目視維持）
3. **Formation**（正しい編隊位置の維持）
4. **Cockpit tasks**（周波数変更、Ops check、スイッチ操作など）
5. **Mission tasks**（ミッションの実行）
6. **SA**（高い状況認識の維持）

教範（IFF §3.8）でも、ウイングマンの優先として「visual, formation, radios」が挙げられておる。
下を向く仕事（Radar も radios も各種スイッチ操作も）は、すべて **Visual（2番目）** と **Formation（3番目）** という土台があってこそ成り立つものたい！

<Highlight>**コックピットタスクは優先の 4 番目たい。最後でも、最初でもない。Visual と Formation を捨てて下を向いた瞬間、居場所は死ぬ。**</Highlight>

### 2. R（Reason）：Ops Check：燃料と機体システムの定期確認

「Ops check（オップス・チェック）」は、単に「暇だから計器ばぼーっと眺める時間」じゃなか！
燃料（fuel）ば含む機体システム全般の定期確認（periodic aircraft systems check）たい。

- **開始の合図:** リーダーの目配せ（visual）または無線（radio）でスタートする。
- **リーダー側の配慮:** リーダーはウイングマンに十分な時間をあたえ、必要なら編隊位置ば少し緩めてやり、急激な機動（abrupt maneuvering）は絶対にやってはいかん約束たい！
- **ウイングマンの作法:** チェック中もリーダーの目視（primary）ば第一にし、コックピットを見るのは**「short glance（一瞬チラ見するだけ）」**たい！
- **高G後の処理:** 高G（>4 G。※T-38の枠組み数値たい）がかかる運動のあとは、G-meterばリセットしてよい。T-4に乗るあんさん達は、自機の相当する計器に読み替えて触ってね。
- **燃料の約束（joker / bingo）:**
  Ops check の一番の目的は燃料（fuel）の確認たい。
  **joker** や **bingo** は、「この燃料残量になったら区切りを付けて次のイベントに移行する／帰投する」という、リーダーと共有する**燃料の定性的な約束**たいね。ポンド数などの具体数値はブリーフィングで決めるもので、丸暗記するもんじゃなか！（※T-38と違ってT-4にはABが無いけん、bingo後にABば切る心配もなかばい）。

### 3. E（Example）：FENCE Check：空域の「IN」と「OUT」で揃える！

訓練空域やルートに入るとき（ENTER）にやるのが **FENCE IN**、出るとき（EXIT）にやるのが **FENCE OUT** たい！

チェック項目は部隊標準（unit standards）やブリーフィングで決まるばってん、T-38教範（Fund 6.5）での例ば見てみんね。

- **例示項目:** fuel（燃料）、altimeter（高度計）、NAVAIDs（航法装置）、G-suit（Gスーツ）、squawk（トランスポンダー）。
- **FENCEの頭字語（Att1B）:**
  - **F**ire control（火器管制）
  - **E**mitters（電波射出装置）
  - **N**AVAIDs（航法装置）
  - **C**ommunications（通信機）
  - **E**lectronic countermeasures（電子対抗手段）

**※ここで注意たい！** T-4には Fire control（火器管制）も ECM（電子対抗手段）も付いとらんばい！
大事なのは具体的なスイッチ名を捏造することじゃなく、空域の入出で設定ば揃える「優先順位」と「short glance（チラ見）の作法」ば持ち帰ることたいね！

### 4. E（Example）：スイッチ操作の作法とチェアフライング

旋回や機動（maneuvering）の最中に、どうやって安全にスイッチば触るか？
教範（IFF §3.8）が教える作法はこれたい！

1. まず正しい編隊位置（formation）ば作る。
2. 触るスイッチば頭の中で決める。
3. コックピットば**一瞬だけチラ見（short glance）**！
4. 操作しながらすぐに顔ば上げ、編隊位置（formation）ば直す！

特に **FENCE OUT** は、編隊の合流（rejoin）や周波数の切り替えが同時に重なってめちゃくちゃ忙しくなる。
だからこそ、地上で**「チェアフライング（机上イメトレ）」**ばやって、手順ば頭の中で先に飛ばしておくのがプロの鉄則ばい！

### 5. P（Point）：評価基準（Vol.2）での不合格の芯

AFMAN 11-2T-38 Vol.2 に「Ops check や FENCE 専用のArea番号」は存在せん（勝手に番号ば新造したらいかんばい）。

評価の芯は第3話と全く同じたい！
スイッチ操作に夢中になって Visual と Formation ば捨て、**「安全な間隔（safe separation）ば失う」**、または**「急激な修正操作（abrupt corrections）しかできない」**状態になったら一発でアウト（不合格）たいね！

## 📝 まとめ：道真のフライトデブリーフィング

Ops check も FENCE check も、単なる作業の丸暗記じゃなか。

CLEAR → Visual → Formation という「居場所」ば完璧に守った上で、チラ見（short glance）でスマートにスイッチば触る。
これができて初めて、お前はコックピットの中で安全に仕事をこなす「プロのウイングマン」になれるったい！

優先順位ば逆転させるな。タスクの本質ばハックして、自律したパイロットになれ！

よし、「第4話：Ops check / FENCE check」編はここまで。

次回はいよいよ、空中で命と責任ば託し合う**「リード交代（Lead Changes）」**の血の掟ばガッツリハックしていくばい！

ラップベルトばしっかり締めて、次のブリーフィングに備えんね！
