## 🎯 今日のミッション（学習目標）

このブリーフィングを終えた時、あんさんは以下の状態になっとるはずたい。

- [ ] Ops Check（オプスチェック）は単に計器を眺める時間ではなく、燃料（fuel：フューエル）を含め、フライトを無事に続けるため（safety of flight：セーフティ・オブ・フライト）の定期確認だと説明できる！
- [ ] 練習機の Ops Check の項目は Cabin altitude（キャビン・アルティチュード）、Oxygen（オキシジェン）、Fuel、Engine（エンジン）だと言える！
- [ ] コックピットタスク（Cockpit tasks：コックピット・タスクス）はウイングマンの優先順位で 4 番目であり、Visual（ビジュアル）や Formation（フォーメーション）を捨てて下を向いた瞬間に「居場所」が消えてなくなると区別できる！

## 📋 概要：下を向くのは、居場所ができてから！

全国のT-4ジェット練習機で空を駆け巡るパイロット学生のあんさんたち！

第3話では、Fingertip（フィンガーチップ）と Route（ルート）という「空中での居場所」の形ば覚えたね！ 自機の Front Cockpit（フロント・コクピット：前席）から長機を見たときの目安で、Fingertip は「前後は主翼 Leading Edge（リーディングエッジ、LE）延長線上、上下は主翼端（Wing Tip（ウイングチップ））とエンジンインテイクのマーキングが一致、左右は主翼 LE 延長線とスタビレータ端が真横の位置」、Route は「2機幅」たい。細かいところは、ブリーフィングで示されたものに従うこと。

自分の立ち位置が作れて初めて、ワシらはコックピット内の仕事（スイッチ操作やチェック）に手を出すことができるとよ。

テキサスのカントリー・バーでバドワイザーばぐびっと飲んだ教官ジョーが、ボトルをコトンと置いて言ったばい。

「いいかミチザネ。下（コックピット内）を向いて仕事をするのは、自分の立ち位置が完璧にできてからだ。順番を間違えて下ばっかり向く奴から、空で迷子になっていくんだよ」

……まさにその通りたい！
本日は、定期的に機体の健康状態を確かめる<strong>「Ops Check」</strong>の作法ば心臓に叩き込むばい！

なお、命がけの「リード交代（Lead Changes：リード・チェンジズ）」は次回（第5話）で教えるけん、楽しみにしとってね！

## 📚 詳細解説：コックピットタスクの作法と優先順位

下（コックピット内）を見るには、命を守る「作法」と「優先順位」がある。
これを破った瞬間に、お前の居場所は消えて無くなるばい！

### 1. P（Point）：コックピット仕事は「4番目」たい！

ウイングマンの優先順位ば見てみんね！

1. **CLEAR!**（クリア：衝突回避・クリアリング）
2. **Visual**（リーダーや他機を目視維持）
3. **Formation**（正しい編隊位置の維持）
4. **Cockpit tasks**（周波数変更、Ops Check、スイッチ操作など）
5. **Mission tasks**（ミッション・タスクス：ミッションの実行）
6. **SA**（Situational Awareness：シチュエーショナル・アウェアネス、高い状況認識の維持）

米空軍の教範でも、ウイングマンの優先として「visual, formation, radios（レディオズ）」が挙げられておる。
下を向く仕事（Radar：レーダー、radios、各種スイッチ操作）は、すべて **Visual（2番目）** と **Formation（3番目）** という土台があってこそ成り立つものたい！

<Highlight>**コックピットタスクは優先の 4 番目たい。最後でも、最初でもない。Visual と Formation を捨てて下を向いた瞬間、居場所は消える。**</Highlight>

### 2. R（Reason）：Ops Check：燃料と機体システムの定期確認

「Ops Check」は、単に「暇だから計器ばぼーっと眺める時間」じゃなか！
燃料（fuel）ば含む機体システム全般の定期確認（periodic aircraft systems check：ピリオディック・エアクラフト・システムズ・チェック）たい。

- **開始の合図:** リーダーの目配せ（visual）または無線（radio）でスタートする。
- **リーダー側の配慮:** リーダーはウイングマンに十分な時間をあたえ、必要なら編隊位置ば少し緩めてやり、急激な機動（abrupt maneuvering：アブラプト・マニューバリング）は決してやってはいかん約束たい！
- **ウイングマンの作法:** チェック中もリーダーの目視（primary：プライマリー）ば第一にし、コックピットを見るのは<strong>「short glance（ショート・グランス、一瞬チラ見するだけ）」</strong>たい！
- **高G後の処理:** T-4 では、G計（G-meter：ジー・メーター）はリセットしない。
- **燃料の約束（joker：ジョーカー / bingo：ビンゴ）:**
  Ops Check の一番の目的は燃料（fuel）の確認たい。
  **joker** や **bingo** は、「この燃料残量になったら区切りを付けて次のイベントに移行する／帰投する」という、リーダーと共有する**燃料の定性的な約束**たいね。ポンド数などの具体数値はブリーフィングで決めるもので、丸暗記するもんじゃなか！

### 3. E（Example）：Ops Check の項目：練習機の4項目！

練習機なので、T-4 の Ops Check の項目はこれたい！

- **Cabin altitude**（キャビン高度）
- **Oxygen**（酸素）
- **Fuel**（燃料）
- **Engine**（エンジン）

大事なのは項目の丸暗記じゃなく、「優先順位」と「short glance（チラ見）の作法」ば持ち帰ることたいね！

### 4. E（Example）：スイッチ操作の作法とチェアフライング

旋回や機動（maneuvering：マニューバリング）の最中に、どうやって編隊ば崩さずにスイッチば触るか？
作法はこれたい！

1. まず正しい編隊位置（formation）ば作る。
2. 触るスイッチば頭の中で決める。
3. コックピットば**一瞬だけチラ見（short glance）**！
4. 操作しながらすぐに顔ば上げ、編隊位置（formation）ば直す！

特に、コックピットの仕事が重なっとるときに Ops Check まで加わると、下を向く回数が増えて、めちゃくちゃ忙しくなる。
だからこそ、地上で<strong>「チェアフライング（机上イメトレ）」</strong>ばやって、手順ば頭の中で先に飛ばしておくのがプロの鉄則ばい！

### 5. P（Point）：評価の芯

評価は概成～習熟たい！ 概成は安全であるが正確ではない状態、習熟は正確にできる状態たい。

## 📝 まとめ：道真のフライトデブリーフィング

Ops Check は、単なる作業の丸暗記じゃなか。

CLEAR → Visual → Formation という「居場所」ば完璧に守った上で、チラ見（short glance）でスマートにスイッチば触る。
これができて初めて、お前はコックピットの中で落ち着いて仕事をこなす「プロのウイングマン」になれるったい！

優先順位ば逆転させるな。タスクの本質ばハックして、自律したパイロットになれ！

よし、「第4話：Ops Check」編はここまで。

次回はいよいよ、空中で命と責任ば託し合う<strong>「リード交代（Lead Changes）」</strong>の血の掟ばガッツリハックしていくばい！

ラップベルトばしっかり締めて、次のブリーフィングに備えんね！
