## 📚 詳細解説：Tactical LABと戦術旋回の血の掟

戦術隊形は、お互いの安全を守る「見張りの箱」たい。
位置どりの修正順から旋回のデフォルトルールまで、脳みそに叩き込め！

### 1. P（Point）：Tactical LAB の箱と位置修正の優先順位

教範（AFMAN 11-2T-38 Fund 6.26 / IFF §3.6）における Tactical LAB の基準はこれたい！

- **進入:** radio「**go tactical**」または視覚 **porpoise**。出ていくときウイングマンは flightpath を clear するばい。
- **距離（横間隔）:** **4,000–6,000 ft**！
  *(※Spread の 1,000–3,000 ft と絶対に混ぜたらいかんばい！)*
- **前後角度:** **0°–10° aft**（基本は真横の **strive 0°** ば目指す！）。
- **高さ（スタック）:** **vertical stack 最大 2,000 ft**（※T-38の枠組み数値たい。見え方は機種で較正する。T-38 のサイトピクチャを T-4 の正解にするな！）。visual に理由が無ければ **stack high**（位置エネルギー）たい。
- **主目的:** 2機が対等に前方と相手の6時方向（背後）ば索敵し合う**「等しい見張り（visual lookout equal）」**たい！

そして、ズレた位置ば直すときの**「修正の優先順位」**は絶対不変たい！ geometry を power より先に直せ。

1. **fore / aft（前後位置）:** まず真横（0°）に合わせる！
2. **lateral（横間隔）:** 次に 4,000–6,000 ft の幅を合わせる！
3. **stack（上下高度）:** 最後に高さを整える！

<Highlight>**戦術隊形は見せ場じゃない。等しい見張りのための箱だ。**</Highlight>

### 2. R（Reason）：戦術旋回（Tactical Turns）の箱と基本原則

広い間隔で 2 機が安全に旋回するための絶対ルールがこれくさ！

- **デフォルトルール:** 無線や wing flash（翼の合図）がない限り、旋回開始はすべて **delayed 90°** たい！
- **Contract:** 速度ば保つ（T-38 は MIL + G。**4 G も 3 G も T-4 の正解にしない**。自機制限に読み替え）。
- **デコンフリクトの鉄則:** 旋回が交差するときは、可能なら常に **「Number 2 always goes high（2番機が上を通る）」** で高度差ば作るばい！

各戦術旋回の箱としての区別ば整理するぞ！

- **check turn（≤30°）:** 「check (deg) left/right」のコールで同時に旋回（contract）。同じ side（側）ば維持する。
- **delayed 45°（30–60°）:** into（ウイングマン側への旋回）ではウイングマンはまっすぐ進みつつ垂直デコンフリクトを行い、リードの rollout（旋回完了）後に opposite side（反対側）へ入る。away（ウイングマンから離れる旋回）は鏡像たい。
- **delayed 90°（>60°）:** 合図（無線や wing flash）が無ければこれ！ into ではリードが先に旋回し、ウイングマンは**まっすぐ進む** → リードの新しい6時方向ばクリア → それから90度旋回して **opposite side** へ入る。away は鏡像。タイミングの目安は**リードが約45°回った頃**たい！
- **hook:** 両機同時・同方向の180度反転。into は **radio 必須** たい！
- **cross:** 互いに into（相手側）へ180度旋回。高度を割り（Number 2 always goes high）、**60–90° で cross（交差）**、横間隔 **2–3 nm** を保つ。見えなければ rollout して「blind」をコールする（※本手順は第10話）。
- **in-place:** 両機が同時・同方向へ90度旋回。終わりは **直前の横間隔の trail（縦並び）** になる！（左右入れ替えではないばい。LAB から入れば結果として 4,000–6,000 ft の縦並びになるだけで、in-place 専用の trail 箱があるわけじゃない。）
- **shackle:** 互いに寄って cross（交差）し、**サイドを入れ替える（左右スイッチ）**、または位置を取り戻す。
- **fluid turn:** エネルギー（余剰推力・G）が少ないとき。**≈45° bank、90° increment（90度刻み）** で速度と高度ば維持して回る。

**※用語の整理:** Fluid turn（エネルギー節約旋回）≠ Fluid formation（第7話の追従隊形）≠ Fluid Maneuvering（FM：戦闘機動 / Area 83）たい！絶対に混同するなよ！

### 3. E（Example）：Tactical Rejoin（戦術合流）のパラメータ

戦術隊形から route / fingertip へ戻るのが **Tactical Rejoin** たい！

- **初動パラメータ:** リードは **350 KIAS / 45° bank / level（水平）**（※T-38の枠組み数値たい。T-4は自機制限に読み替え）！
- **厳禁:** 第8話で学んだ通常合流（admin の 300 KIAS / 30° bank）と絶対に混ぜてはイカンばい！
- **直線合流（straight-ahead）:** 今いる side へ。**lead の 6 時を横切るな**（4-ship 準備の思想。小説はせんでよい）。
- **旋回合流 into:** 外側から入り、6 時を **clear** してから inside。away は追いつき過ぎ（AA / closure）に注意。6 時クロス禁止を「合流全部」に一般化するな！

### 4. P（Point）：評価基準（Vol.2）の真実

AFMAN 11-2T-38 Vol.2 Table 3.1 における評価エリアはこれたい！

- **Area 81 Tactical（Wing）:**
  本話の主評価エリア！Q の語は **tactical 位置 / deconflict / mutual support**。不合格（U）は **位置喪失 / deconflict 重大 / support なし** たい！
  *(※等しい見張りは LAB の理由。Area 81 の support と混ぜるな。)*
- **Area 82 Tactical Rejoin（Wing）:**
  戦術合流の専用評価エリア！**unsafe / 未完** が不合格（U）たい！
  *(※Area 83 は FM、Area 79 は第8話の通常 Rejoin、Area 67 は Tactical Lead。本話の主にしたらイカンばい！)*

*(※4機編隊の短い注記：4機（4-ship）で飛ぶ際、各ウイングマンは必ずエレメントリードを目視維持（MUST visual with element lead）しなければならんばい。#2 が stack を set する。Wall / Fluid Four の小説はせんでよい。BD check と編隊着陸は第10話の末尾。)*

## 📝 まとめ：道真のフライトデブリーフィング

Tactical LAB も戦術旋回も、ただカッコよく飛ぶためのアクロバットじゃなか。

4,000–6,000 ft という広大な箱で真横（strive 0°）ばキープし、お互いの死角ば見張り合う（visual lookout equal）。
そして、合図のない旋回開始には delayed 90° と Number 2 always goes high で確実にデコンフリクトする。
これができて初めて、お前は空中で背中ば預け合える「自律したパイロット」になれるったい！

思い込みで動くな。戦術幾何学の本質ばハックして、自律したパイロットになれ！

よし、「第9話：LAB / tactical turns / lookout」編はここまで。

次回はいよいよ、第1シーズンのクライマックス！ 僚機を見失った時と緊急停止を学ぶ**「Lost wingman / Knock-It-Off（KIO）」**の血の掟ばガッツリハックしていくばい！
