## 🎯 今日のミッション（学習目標）

このブリーフィングを終えた時、あんさんは以下の状態になっとるはずたい。

- [ ] 長機の後ろでも箱が違う！ Close Trail（クローズトレイル：1機長後方・下方）≠ Fighting Wing（ファイティングウイング：2〜6° AA、1,000〜2,000 ft）と位置と目的を説明できる！
- [ ] Close Trail で主翼・スタビ・間隔の「等間隔」とフラップヒンジを目印にブラスト直下を保ち、急激な修正操作を避けて旋回（60度バンク基準）に追随できる！
- [ ] 間隔喪失時の terminate（ターミネート：機動停止）と重大事態における Knock-It-Off（ノックイットオフ：訓練中止）の根本的な違いを区別して説明できる！

> <strong>立場の明確化:</strong> 本記事は編隊飛行の基礎概念を理解するための学習支援教材であり、防衛省・航空自衛隊等の公式な飛行規程、訓練基準、および運用手順の代替ではない。実機の操縦および訓練においては、常に当該機の正規の飛行規程および担当教官の指示が最優先される。

## 📋 概要：後ろなら全部同じはブルシット！

地平線の彼方まで遮るもののない、突き抜けるような青空！
広大な訓練空域を駆け巡るパイロット学生のあんさんたち、日々のフライトご苦労ばい！

第6話では、見張りと航法のための広い隊形「Spread（スプレッド）」を学んだね。
本日は、長機の後方コーン内で位置を保ちながら追従する<strong>「Trail 族」――Close Trail / Fighting Wing / Extended Trail（エクステンデッドトレイル） / Fluid formation（フルイドフォーメーション）――</strong>の掟を解き明かしていくばい。

荒野のハイウェイ沿いにあるダイナーで、ぶ厚いTボーンステーキを平らげた教官ジョーが、巨大なアイスティーのグラスをガツンと置いてこう吠えたたい。

「おいミチザネ！ 『長機の後ろを飛ぶ隊形ならどれも同じだろ』などとナメたことを考えている奴は、ただのブルシットだ！ 距離も角度も、飛ぶ目的も箱ごとに全く違うんだよ！」

ガハハ！ まさにジョーの言う通りじゃ。
ひとくちに「後ろ」と言うても、長機への精密な追随を身体に叩き込む訓練なのか、戦闘訓練の自在な機動なのか、それとも編隊での作戦行動なのかによって、入るべき位置もやってはいかん禁じ手もまるで異なる。

後ろの箱ごとの役割を理解し、境界線を厳格に保てるようになってこそ、長機から背中を預けられる真の僚機になれるとよ。
なお、Pitchout / Rejoin / Overshoot / Breakout（ピッチアウト・合流・行き過ぎ・離脱）の手順は次回（第8話）でじっくり扱うけん、楽しみにしとってね！

## 📚 詳細解説：Trail族の4大隊形と掟

広大な空に描かれる、長機後方の「4つの箱」。まずはその全体像を比較整理してみよう。

### Trail族 4大隊形の比較表

| 隊形名 | AA | 距離（レンジ） | 特徴・T-4および実戦での位置づけ |
| :--- | :--- | :--- | :--- |
| <strong>Close Trail</strong> | 長機の直後直下 | 1機長後方 かつ 下方 | 追随訓練専用（実運用での蓋然性は低い）。ブラスト直下を維持、60度バンク（2G）基準、垂直アクロ禁止 |
| <strong>Fighting Wing</strong> | 2〜6° AA | 1,000〜2,000 ft | 機動性に富み、将来の戦闘訓練で常用。急激なアクロは行わず、T-4前期課程では未実施 |
| <strong>Extended Trail (ET)</strong> | 30〜45° AA（参考） | 1,000〜3,000 ft（参考） | T-4はレーダー非搭載のため不使用。他機種等の機動練習用 |
| <strong>Fluid formation</strong> | 3/9 ラインより後方 | 広範囲 | 4機での戦闘隊形（OCA等で使用）。真後ろ（6時）に長居せず、状況に応じて柔軟に運動 |

※AA＝Aspect Angle（アスペクトアングル）：長機の尾部から測る角度。長機の真後ろ（6時）を0°として、長機から見た自機の位置が何度横にずれとるかを表す。真横で90°。自分の機首の向きは関係なか。
※OCA＝Offensive Counter Air：攻勢対航空作戦。

### Close Trail：視覚的リファレンスと急激な操作の厳禁

Close Trail は、長機の後方わずか <strong>1機長後方 かつ 下方</strong> という極めて近い距離に入る追従隊形たい。

実戦や普段の運用でこの隊形を使う蓋然性は極めて低いばってん、T-4の訓練課程では「長機の動きに狂いなく追随する感覚」を研ぎ澄ますための基礎科目として組み込まれとる。

ここで頼るべきは、目で捉える視覚的リファレンス（目印）じゃ。

- <strong>上下（高さ）の目印:</strong>
  長機の主翼、スタビレーター（水平尾翼）、そして主翼とスタビレーターの間隔が、上下に<strong>「等間隔」</strong>に見える位置を保つ。
  この等間隔を維持できている状態こそが、エンジンの排気流（ブラスト）のすぐ直下を正しく飛んでいる証拠たい。
- <strong>前後の目印:</strong>
  長機のスタビレーター翼端が、主翼下にある<strong>「フラップのヒンジの間」</strong>あたりに見える位置関係をキープする。

Close Trail で最も警戒せねばならんのは、位置のずれに焦って<strong>急激な修正操作</strong>を入れてしまうことたい。
焦って操縦桿を急激に引いたり押し込んだりすれば、長機へ過接近して衝突の危険を招くか、あるいは直上のブラスト（排気後流）に突入して機体のコントロールを乱してしまう。
具体的な減点数値が定められているわけではないが、教官は「滑らかに修正できているか」「急激な操作で長機を脅かしていないか」を鋭い眼光で見極めとるばい。

なお、Close Trail での旋回は <strong>60度バンク（約2G）</strong> が基準となる。宙返りのような垂直面の激しいアクロバット機動は行わんけん、長機の傾きを先読みしながら滑らかに追随する技を磨くのじゃ。

### Fighting Wing と Extended Trail：境界線と2つの合言葉

次に、実戦的な機動を担う2つの隊形について見ていこう。

- <strong>Fighting Wing:</strong>
  - 角度は <strong>2〜6° AA</strong>、距離は <strong>1,000〜2,000 ft</strong> の円錐状のエリアに位置する。
  - 機動性に富んだ隊形であり、戦闘訓練や部隊運用においてよく使われる重要なポジションたい。
  - ただし、T-4の前期課程では実施せず、将来の戦闘機課程や実戦部隊で本格的に身につけていくことになる。
  - この隊形はアクロバットを行うためのものではなく、長機の指示に対しては「2」と短く受諾を返すのが基本じゃ。
- <strong>Extended Trail（ET）:</strong>
  - 機動追従訓練などで使われることのある隊形じゃが、<strong>T-4にはレーダーが搭載されていないため、T-4課程では使用せん</strong>。

ここで、将来どの機種へ進んでも必ず知っておかねばならん超重要概念がある。それが <strong>terminate</strong> と <strong>Knock-It-Off</strong> の使い分けじゃ！

- <strong>terminate（機動停止）:</strong>
  機動中に間隔（間合い）を崩してしまったり、位置関係を立て直したい時、ウイングマンから長機へ「一旦、旋回や機動をやめて水平直線飛行に戻してほしい」と求める合図たい。単なる訓練終了の合図ではなく、「仕切り直し」を求める言葉じゃ。
- <strong>Knock-It-Off（訓練中止）:</strong>
  長機への異常接近、見失い（Lost Sight：ロストサイト）、想定外の危険領域への侵入など、編隊の保全に疑義が生じた瞬間に、即座に叫んで訓練そのものを中断させる合図たい。

「間隔を崩したから立て直したい」なら terminate、「危険が迫っている、これ以上続けたらまずい」なら Knock-It-Off。この2つの境界線を曖昧にしてはならんばい！

### Fluid formation：戦術隊形と「後ろの箱」の真髄

4つ目の隊形である <strong>Fluid formation</strong> は、4機編隊による戦闘隊形として用いられる。

- <strong>位置と役割:</strong>
  長機の <strong>3/9（サンキュー）ライン（機首と直交する真横のライン）より後方</strong> に位置し、ウイングマンに機動や周囲警戒の柔軟な余裕を与える。
- <strong>実戦での使われ方:</strong>
  特に、敵の航空戦力が存在する経空脅威下における <strong>OCA</strong> などの任務で威力を発揮する隊形たい。
- <strong>してはいけないこと:</strong>
  自由度が高い隊形とはいえ、長機の真後ろ（6時）に漫然と長く居座ってはならん。敵からの格好の標的となり、編隊の視覚的な死角を生み出してしまうけんね。

同じ「後ろ」であっても、Close Trailのように指先ひとつの精度で追従する訓練隊形もあれば、Fluid formationのように戦闘空間で柔軟に生き抜くための戦術隊形もある。
自分が今「どの目的で、どの箱に入っているのか」を常に自覚すること。それこそがプロフェッショナルの飛び方たい！

## ☕ 空中待機（Holding：ホールディング）：道真の燃料補給

テキサスの乾いた夕暮れ、地平線が赤銅色に染まっていく光景は見事なもんたい。
カントリーソングが流れるバーのテラス席で、炭火で炙った梅ヶ枝餅をかじりつつ、冷えたルートビアを豪快に喉へ流し込む……。この独特の薬草の香りと濃厚な甘みが、フライトで火照った頭を心地よく冷ましてくれるばい。

「後ろを飛ぶ」というのは、長機にただ引っ張られることじゃなか。
長機の機動を読み、排気の後流を見極め、適切な間隔と角度を維持し続ける、極めて能動的な仕事たい。
神の世界でも、主神の後ろを固める従者が位置取りを誤れば、たちまち陣形が崩れてしまうけんね。

おっと、ブーツの足音を響かせてジョー教官がやってきたばい。
カウボーイハットの鍔を押し上げ、鋭い眼光を光らせておられる。本日の口頭試問、気合を入れて挑まんね！

## 🗣️ ブリーフィング口頭試問：教官ジョーの突っ込み！

教官ジョーはフライトログをバンとテーブルに叩きつけると、パイロット学生の顔を正面から睨みつけた。妥協を許さない冷徹な視線が突き刺さる。

<strong>教官ジョー</strong>：「おいウイングマン。お前、今日のフライトで Close Trail に入ったとき、長機との間隔が詰まったのを見て慌てて操縦桿を引っこ抜いただろう。おまけに Fighting Wing と Fluid formation の違いも答えられなかったそうだな。……おい、このフライトのどこがブルシットか分かっているのか？」

<strong>学生</strong>：「は、はい！ Close Trail で遅れまいと焦ってしまい、急激な引き起こしで修正しようとしました！ また、どちらも長機の後ろに位置する隊形なので、同じような感覚で追従できると考えていました！」

<strong>教官ジョー</strong>：「<strong>ブルシット！！！ お前は長機と空中接触するか、ブラストに突っ込んで機体を叩き落とされたいのか！？</strong>」

<strong>学生（白目）</strong>：「め、滅相もございません！ 接触など真っ平ごめんです！」

<strong>教官ジョー</strong>：「Close Trail は訓練専用の超近接追従だ！ 上下の等間隔とフラップヒンジの目印を外さず、ブラスト直下を滑らかに維持するのが鉄則だぞ！ そこで急激な修正操作を入れるなど、技量未熟の極みだ！
さらに、将来の戦闘訓練で常用する Fighting Wing と、4機編隊でOCAなどに用いる Fluid formation では、戦術的な目的も箱の深さもまるで違う！

おいウイングマン、Close Trail の目印と、間隔喪失時のコールを言ってみろ！」

<strong>学生</strong>：「は、はい！ Close Trail では、長機の主翼・スタビ・その間隔が上下に『等間隔』に見え、スタビ翼端が『フラップヒンジの間』に見える位置を維持します！ 急激な操作は厳禁で、60度バンクを基準に追従します！
また、機動中に間隔を喪失して立て直したい時は terminate（ターミネート）で長機に機動停止を求め、重大な危機に直面した時は Knock-It-Off で直ちに訓練を中断します！」

<strong>教官ジョー</strong>：「……そうだ。後ろを飛ぶ者こそ、冷静に目印を捉え、滑らかな操作で位置を保たねばならん。焦って舵を荒く動かす奴に、長機の背中は任せられない。よし、ブリーフィングは合格だ。明日のフライトでは指先ひとつで滑らかにコントロールしてみろ！」

## 📝 まとめ：道真のフライトデブリーフィング

今日の空で学んだ Trail 族の要諦、しっかり頭に刻み込めたかい？

「後ろを飛ぶ」というのは、決して受動的な追従ではない。
- <strong>Close Trail:</strong> 訓練のための基礎。主翼・スタビの等間隔とフラップヒンジを頼りに、急激な操作を排してブラスト直下を精密に飛ぶ。
- <strong>Fighting Wing:</strong> 将来の戦闘訓練で常用する機動性の箱。
- <strong>Extended Trail:</strong> T-4では使わん隊形。
- <strong>間隔を失ったら:</strong> terminate（機動停止）と Knock-It-Off（訓練中止）を峻別する。
- <strong>Fluid formation:</strong> 4機の戦闘隊形として、真後ろに居座らず戦術的な余裕を保つ。

境界線と規律を正しく保ててこそ、あんさんは長機が確信を持って前方を睨める「本物の相棒」になれるばい。

さて、第7話はここまで！
次回はいよいよ、編隊の離脱と合流の真髄である<strong>「Pitchout / Rejoin / Overshoot / Breakout」</strong>に挑むけんね。
空の風のように力強く、次のブリーフィングに備えておくのじゃぞ！
