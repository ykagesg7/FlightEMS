## 🎯 この記事は誰のため？ 何が持ち帰れる？

T-4 で前期課程を飛んどるあんさん向けの1本たい。曲技の課目で **Cloverleaf（クローバーリーフ）** をブリーフィングで説明できるようになるのがゴールばい。

読み終えたら、次の3つが言えるようになる。

- [ ] 目的を一句で：**垂直機動の中で、エネルギーを管理しながら意図した方向へ90°向きを変える。**
- [ ] 1枚の Leaf の流れ：3G で Pullup → 約60°Pitch で Roll しながら引く → Inverted level で 150 kt 以上 → Split-S に似た Pullout → 開始速度の 350 kt で水平線を通過。
- [ ] よくある失敗：**最低速度 150 kt の見落とし、Abort の遅れ、方向のアンダーシュート、最低高度の認識不足、回復操作の不良。**

数値は T-4 を参照しとる。機種によって数値は変わる。**自機の数値は、飛行規程と教官のブリーフィングが正本たい。**

## 📖 先に用語をそろえる

初めて出る言葉は「英語（カタカナ）」で書き、以降は英語で書くばい。

| 用語 | 意味 |
|------|------|
| **Leaf（リーフ、葉）** | Cloverleaf を構成する1回分の機動。Pullup から Pullout までで1枚。上から見ると四つ葉のクローバーの葉1枚に見える。 |
| **Heading（ヘディング、機首方位）** | 機首が向いている方位。各 Leaf の進入方位は、前の Leaf から **90°** ずつ回る。 |
| **Pitch（ピッチ）** | 機首の上下の角度。「60°Pitch」は機首が水平線より60°上。 |
| **Bank（バンク）** | 機体の左右の傾き（傾斜角）。 |
| **Roll（ロール）** | 機体を前後軸まわりに回して Bank を変える操作。 |
| **Border（ボーダー、空域境界）** | 割り当てられた訓練空域の端。 |
| **Box（ボックス）** | 曲技を行う立体の空域枠（前後・左右・上下の広がり）。大きさは機種と規程、教官が決める。[第14話](/articles/cp-5-1-aerobatic-contract)で扱った「Box と計画高度」の続きたい。 |
| **MIL（ミリタリー）** | ミリタリー推力。アフターバーナーを使わない最大推力。**T-4 にアフターバーナーはない**ので、自機の出力設定は規程で確認する。 |
| **Pullup（プルアップ） / Pullout（プルアウト）** | 引き起こし／引き下ろし（降下から水平へ戻す引き）。 |
| **Inverted level（インバーテッド・レベル）** | 背面のまま水平な姿勢。 |
| **Light buffet（ライト・バフェット）** | 失速に近づく手前で出る、軽い機体の振動。「これ以上引くと失速側」という目安になる。 |
| **Vs（失速速度）** | 失速する速度。T-4 の巡航形態ではおおむね **120 kt**。 |

## 📋 概要：同じ向きで、四回

Cloverleaf は、上から見ると四つ葉のクローバーに見える機動たい。4枚を同じ回転方向で、90°ずつ方位をずらして描く。

途中で回転方向を逆にすると、Leaf がねじれて Cloverleaf ではなくなる。

---

## 🧭 この曲技の目的：垂直機動中の90°方向変換

Cloverleaf の狙いは、**垂直機動の中で90°向きを変えること** たい。

縦に引き上げながら、速度と高度のエネルギーを管理して、意図した方向へピタリと向きを変える。これが空中感覚を養うのにとても優れとる。戦闘機乗りには必須の感覚たいね。

四つ葉の形は、その感覚を4回続けて確かめるための「答案用紙」みたいなもんばい。

---

## 📚 詳細解説

### 原則：同じ向きに4枚、各 Leaf は90°ずつ

<Highlight>「**同じ向きに4枚の葉を描け。各葉は前から90°。頂点でエネルギーを確かめろ**」</Highlight>

### 1枚の Leaf の流れ

| 局面 | やること |
|------|----------|
| ① 進入 | **350 kt / 94% rpm** |
| ② Pullup | **3 G** で引き起こす |
| ③ Roll しながら引く | Nose **約60°上げ** の Rolling pull（Roll と引きを同時に）で、方位を90°回す |
| ④ Inverted level | **150 kt 以上** |
| ⑤ Pullout | **Split-S に似た** 引き下ろし。**Light buffet** を目安にまっすぐ引き、**350 kt** で水平線を通過 |

空域は、縦×横 3 nm、上方 5 kft。

③では、90°先の目標の真上に機首がくるように、徐々に Bank を深める。Pitch 入力は維持しとかんと、④で 150 kt を切るばい。

④の頂点で、まず速度と高度を確かめる。150 kt 以下なら、いったん課目を **Abort** して回復する。

⑤は Light buffet を維持しつつ、引き起こし完了時に 350 kt になるように Pitch rate を調整せなんばい！ ここで 350 kt に戻せれば、次の Leaf の進入速度がそのままそろう。

### 回復操作：1.3Vs で Roll して立て直す

T-4 の巡航形態での失速速度は、おおむね **120 kt** たい。余裕をみて **1.3Vs（約 150 kt）** で Roll し、姿勢を立て直す。

だけん、背面で 150 kt を割ったら「まだいける」と粘らんこと。その時点で余裕を使い切っとるけん、すぐ回復操作に移るとよ。

### よくある失敗

演習でよう見る失敗はこの5つたい。

1. **最低速度 150 kt を認識しとらん。** 頂点で速度計を見とらんけん、割っとることに気づかん。
2. **認識したのに Abort せん。** 150 kt 割れに気づいても、形をそろえたい一心で回復操作に移らん。
3. **意図した方向の手前でアンダーシュートする。** 理由は次の節で説明するばい。
4. **最低高度 5,000 ft の認識不足。** Pullout で高度計を見とらん。
5. **回復操作の不良。** 1.3Vs の余裕を待たずに Roll したり、引きすぎて失速側に入ったりする。

### なぜアンダーシュートするのか

60°Pitch の姿勢から Roll を入れた瞬間から、飛行機が目標の方向へ進もうとする横向きの勢いは、Roll が深くなるほど減っていく。

はじめに Roll を入れすぎると、Pitch で引いても、もう目標の方向へ向かう勢いが残っとらん。結果、90°回りきらずに手前で止まる。

だけん、Roll は一気に入れんで、目標の真上に機首が来るように **徐々に** 深めるとよ。Pitch を引き続けながら、Roll で方向を「配る」感じたい。

### 📎 補足：CPL（事業用操縦士）ではどう扱われる？

国交省航空局（JCAB）の事業用操縦士の実地試験（令和7年12月改正の実施細則）では、空中操作の科目は **低速飛行・失速と回復操作・急旋回（45°）・螺旋降下・型式特性に応じた操作** たい。Cloverleaf のような曲技は試験科目に **入っとらん**。

ばってん、「失速の兆候を察知して、機を失せず回復する」「速度と姿勢の変化を読んで操舵する」という中身は、そのまま Cloverleaf の頂点での速度確認や Light buffet の扱いと同じ根っこたい。曲技で速度計を見る癖がついとれば、CPL の失速科目でも慌てんで済むばい。

## 📝 まとめ：道真のデブリーフィング

Cloverleaf は、四つ葉の形を描く曲技であると同時に、**垂直機動の中で意図した方向へ向きを変える** 空中感覚の稽古たい。ブリーフィングで言うのは一句で足りる。

**「同じ向きに4枚の葉を描け。各葉は前から90°。頂点でエネルギーを確かめろ。」**

ワシも若い頃、最初の葉で Roll を一気に入れすぎてな。90°回るつもりが60°くらいで止まって、四つ葉どころか三角おにぎりみたいな航跡になった。おまけに頂点で速度計ば見たら 150 の手前でしょんぼりしとって、後ろの席から教官の「Abort!」が飛んできたばい。ガハハ！ 幸運の四つ葉は、Roll を焦らず、頂点で速度計を見るもんにだけ生えるっちゃん。

次は CP シリーズの最終話、**Chandelle（シャンデル）** たい。180° 旋回しながら高度を取り、翼水平で終わるのに「水平飛行ではない」機動ばい。
