# F1 トップ「最新情報」（home-announcements）

トップページの「最新情報」に、お知らせカードが API 応答と整合して表示されるかを見る。

## Sub-features

- `f1-guest-load` 匿名で一覧が読み込まれる
- `f1-guest-filter` ゲスト表示で開発向けタイトルが除外される
- `f1-auth-load` ログイン後も一覧が表示される（除外ルールは未確認のまま報告可）

## How to get to it (user POV)

- ブラウザで `/` を開く（ヘッダーから戻るでも可）。

## Driving it with Playwright

Preconditions:

- Doctor 合格。Network は Preserve log / Disable cache 推奨。

- **開く。** `page.goto('/')`。読み込み中の灰色プレースホルダが出る。
- **最新情報へ。** 「最新情報」見出しまでスクロール。カード枚数と各カードの題名・日付を数える。
- **Network（主証拠）。** `GET .../rest/v1/announcements?select=*&order=date.desc&limit=5` の **HTTP 200**、配列の **件数**、各要素の `id`・`title`・`date` を表に書く。
- **突き合わせ。** 匿名時は `src/utils/guestAnnouncements.ts` の除外後と画面カードが一致する〔計測〕。
- **ログイン時。** F2 完了後に 1〜3 を繰り返す。
- **補足証拠。** エラー文言・空状態文言が出ていないこと、Console 全文（dev では有効。preview では Console は補足のみ）。

### 合格

- announcements の GET が **200**。
- 応答 JSON 配列の **件数** が記録できる。
- 画面カードの **枚数と題名・日付** が、ゲスト時は除外ルール適用後の応答と一致する〔計測〕。
- （補足）致命的なエラー UI やお知らせ欄専用の失敗文言が出ていない。

### 不合格

- GET が 4xx/5xx、または配列でない。
- 200 でもカード枚数・題名が応答と一致しない（除外ルールを適用したあとでも）。
- お知らせ欄に読み込み失敗・エラー専用の表示が出る。

### 判断不能

- `/` に届かない（dev 未起動、Supabase 未設定でアプリが起動直後に落ちる、など）。
- 本番 DB 接続は匿名 GET のみなら F1 は実行可だが、**ローカル検証が要件のとき** 資格情報がなくローカルが起動できない。
- カルーセルがアニメーション中だけで、安定した枚数が数えられない（再試行後も同じなら不合格へ）。

## Gotchas

- 匿名で `POST .../auth/v1/token?grant_type=refresh_token` が 400 になることがある〔計測〕。F1 単体の不合格根拠にしない。
- `useReveal` 後にカードが出る。固定 sleep より見出し・カードの locator を待つ。
- ログイン中にゲスト除外がかかるかは **不明**。違いがあれば〔計測〕で報告し、合格判定はゲスト経路を主とする。
